## 🚀 About

This website serves as my digital profile and portfolio, designed with modern web standards, lightweight styling, and an emphasis on clean architecture, performance, and accessibility.

### Key Highlights
- **Zero Heavy Frameworks**: Pure semantic HTML5, modern vanilla CSS, and minimal vanilla JavaScript.
- **Dark Mode Aesthetic**: Refined dark slate theme with ambient lighting and brand-themed tech badges.
- **Fully Responsive**: Fluid layout optimized for mobile devices, tablets, and desktop displays.
